# Unleashing the Power of WebAssembly System Interface (WASI) in Go

WasmCon 2023, Virtual, 6th–7th September 2023

- Rajiv Ranjan Singh

## About

WebAssembly System Interface (WASI) gives WebAssembly modules a portable way to talk
to the outside world — files, clocks, sockets, and environment — without binding to a
single operating system. This talk covers what WASI is, how Go compiles to it, and
what the Go and WebAssembly toolchain makes possible today.

WasmCon 2023 was hosted by the Linux Foundation at the Hyatt Regency, Bellevue,
Washington. This talk was presented remotely.
